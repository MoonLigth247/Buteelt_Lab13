# PROJECT.md — Personal Task Tracker

## Сонгосон сэдэв
**Personal Task Tracker** (Бие даалт 13-ийн 2-р сонголт)

## Зорилго
Хэрэглэгч өдөр тутмын ажлуудаа удирдах боломжтой жижиг вэб програм.  
CRUD, дуусах хугацаа, тэргүүлэх чиглэл, шошго, хайлт/шүүлтүүр зэрэг үндсэн боломжуудыг хэрэгжүүлнэ.

## Scope (хамрах хүрээ)

### In scope
- Task CRUD (Create, Read, Update, Delete)
- Due date тохируулах
- Priority (Өндөр / Дунд / Бага)
- Label / Tag оноох
- Search & Filter
- Local Storage persistence
- Responsive UI

### Out of scope
- User authentication
- Multi-user / team feature
- Push notification
- Mobile native app

## Технологи
- **Stack**: Next.js 14 + Supabase + Tailwind CSS
- **Frontend**: Next.js (App Router), React 18
- **Backend/DB**: Supabase (PostgreSQL + Auth)
- **Styling**: Tailwind CSS
- **Testing**: Jest + React Testing Library
